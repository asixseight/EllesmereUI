# EllesmereUI

A World of Warcraft UI suite: unit frames, raid frames, bars and skins that replace or restyle Blizzard's interface.

## Language

### Unit interaction

**Unit Menu**:
Blizzard's right-click popup for a unit, opened securely from our unit and raid frames.
_Avoid_: context menu, right-click menu, dropdown

**Context Menu**:
The click-cast binding action that opens the Unit Menu. Only a binding label, never the popup itself.

**Quick Actions**:
Our strip of colored buttons docked to an open Unit Menu, one button per common action that applies to that unit.
_Avoid_: action buttons, menu buttons, shortcut bar

**Action Color**:
The color of a Quick Action, which stands for what the action does rather than the action itself. Green adds to a group, red leaves or removes from one, yellow is an exchange.
_Avoid_: button color, theme color
